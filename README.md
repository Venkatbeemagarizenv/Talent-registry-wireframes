# Talent Registry Wireframes

UI/UX wireframes for the Talent Registry application.

## Live Preview

- **Branded Version:** [View Wireframes](https://zenvinnovations.github.io/Talent-registry-wireframes/)
- **Original Grayscale:** [View Original](https://zenvinnovations.github.io/Talent-registry-wireframes/wireframes-original/)

## Screens (35+)

| Role | Screens |
|------|---------|
| **Shared** | Login, OAuth Callback, 404 |
| **Student** | Dashboard, Profile, Browse Openings, Opening Detail, My Applications, Application Detail, Chat, Calendar, Notifications |
| **Enterprise** | Signup, Pending Approval, Dashboard, Post Job, My Jobs, Talent Search, Talent Detail, Pipeline, Chat |
| **HR Admin** | Dashboard, Enterprises, Enterprise Detail, Job Approvals, Pipeline Kanban, Application Detail, Calendar, Chat, Students, Audit Log |
| **System Admin** | Dashboard, Configuration, Feature Flags, Success Stories |

## Structure

```
├── index.html              # Navigation hub
├── assets/wireframe.css    # Branded styles
├── student/                # Student portal screens
├── enterprise/             # Enterprise portal screens
├── hr/                     # HR admin screens
├── admin/                  # System admin screens
├── shared/                 # Login, 404, etc.
└── wireframes-original/    # Grayscale version
```
